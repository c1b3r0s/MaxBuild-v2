## Visão Geral 🧶

O projeto **BT3+** foi criado visando entregar um suporte completo para criadores de mods em suas ISOs de BT3. Conhecido anteriormente como **MaxBuild**, o projeto entrega uma expansão robusta de conteúdo e conta com recursos adicionais para uma experiência customizada.

## Features 🎇

* **295 IDs de Personagens:** Conta com 290 personagens jogáveis (0-160 / 170-295), oferecendo 129 IDs adicionais além dos originais para customização completa. 
* **57 IDs de Mapas:** Conta com 51 mapas jogáveis (0-34 / 40-57), entregando 17 vagas adicionais além dos originais.
* **61 IDs de Músicas:** Conta com 57 faixas disponíveis para instalação (0-19 / 20-57). *(IDs 20-57 possuem ajuste de decibéis/dB)*.
* **Interface Aprimorada (UI/UX):** Parte das artes do jogo foram reformuladas para uma melhor experiência visual.

## Visão Técnica 🔨

* **Código Limpo:** Todo o código foi reescrito do zero, de forma organizada, estruturada e seguindo boas práticas de desenvolvimento.
* **Tratamento de Erros:** Funções acopladas ao código-fonte tratam exceções em tempo de execução para evitar travamentos (*crashes*).
* **Suporte a Framework:** Utilização do **ee-forge Framework** para organizar e otimizar o código MIPS64 R5900 de forma pragmática.
